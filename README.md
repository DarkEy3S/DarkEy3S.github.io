# Sevak Martirosyan — Portfolio

Multilingual personal portfolio built with Next.js, React and TypeScript. The site is published with GitHub Pages from the `main` branch using GitHub Actions.

- Russian: `/ru/`
- Armenian: `/hy/`
- English: `/en/`

## Local development

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
```
