# Как редактировать портфолио

Весь контент лежит в `content/`, а компоненты страниц от него не зависят.

| Файл | Что в нём |
|---|---|
| `content/site.ts` | адрес сайта, email, Telegram |
| `content/data.ts` | общие данные: проекты (slug, статус, стек, ссылка, обложка), периоды работы, стек |
| `content/ru.ts`, `hy.ts`, `en.ts` | все тексты интерфейса и проектов на каждом языке |
| `content/types.ts` | типы: если чего-то не хватает в переводе, сборка упадёт с ошибкой |
| `content/metrics-draft.md` | черновики метрик, на сайте не показываются |

Пустые и необязательные поля на сайте не выводятся: блоки «Задача», «Моя роль», «Что я сделал», «Технологии», «Результат» и «Сайт» появляются только после заполнения. Если пусты и email, и Telegram, раздел контактов скрыт целиком.

## Перед публикацией

1. В `content/site.ts` укажи `url` (например, `https://домен`), `email` и `telegram`. Без `url` не генерируются sitemap и абсолютные canonical- и hreflang-ссылки.
2. Запусти `npm run build`. Готовый статический сайт окажется в папке `out/`.

## Добавить проект

1. Добавь slug в тип `Slug` в `content/types.ts`.
2. Добавь запись в `projects` в `content/data.ts`:
   ```ts
   { slug: 'new-site', status: 'draft', group: 'agency', company: 'shake',
     link: 'https://example.org/', cover: { type: 'external', hue: 150 }, stack: ['WordPress'] },
   ```
   - `group`: `current` — текущая работа, `agency` — сайты студий (группируются по `company`), `pet` — личные пет-проекты (секция «Пет-проекты», без компании).
   - `company`: для `current` и `agency` — `uroven`, `01cat`, `shake` или `redline`. Период по умолчанию берётся из компании. Свой: `period: { from: '2024-01', to: '2024-03' }`.
   - `repo` — GitHub, `link` — публичное демо (только проверенный адрес).
3. Добавь тексты с тем же slug в `projects` каждого языкового файла:
   ```ts
   'new-site': {
     title: 'Название', summary: 'Одно-два предложения', alt: 'Описание обложки',
     task: '…', role: '…', implemented: ['…'], results: [{ text: '…', confirmed: false }],
   },
   ```
   Обязательные поля — `title`, `summary` и `alt`, остальные можно не заполнять.
4. Когда тексты на всех трёх языках готовы, поменяй `status` на `'published'`.

## Черновики

- `status: 'draft'` полностью скрывает проект: его нет ни на главной, ни среди страниц, ни в sitemap.
- Результат с `confirmed: false` не показывается, даже если проект опубликован.

## Изображения

- **Портрет.** Положи файл `public/images/sevak-martirosyan.jpg` (квадрат, от 800×800). Он сам появится в карточке профиля на главной и в Open Graph. Alt берётся из `hero.photoAlt`.
- **Скриншот проекта.** Положи файл в `public/images/projects/` и укажи `cover: { type: 'screenshot', src: '/images/projects/имя.webp' }`. Используй только свои скриншоты, без данных клиентов. Для закрытой админки оставь `type: 'mockup'`: это синтетический макет на демо-данных.
- **Абстрактная миниатюра с доменом.** `cover: { type: 'external', hue: 0–360 }`, где `hue` — оттенок цвета.
- **Схема списка задач.** `cover: { type: 'todos' }` — синтетический макет, тексты из `pets.mock`.

## Проверить ссылку

1. Открой ссылку в браузере и убедись, что сайт доступен и это действительно тот проект.
2. Укажи полный адрес с `https://` в поле `link`.
3. После `npm run dev` проверь кнопку «Открыть сайт» на карточке и на странице проекта.
